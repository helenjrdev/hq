## Get Started
### Prerequisites
#### Git Repo
Open your terminal and change the directory to where you want to save this project.
```bash
cd path/to/your/project
```

Clone the repository.
https://github.com/helenjrdev/hq.git


### Installation
#### Git
Open your terminal to check if you have Git.

macOS, Windows, and Linux
```bash
git version
```
If your output doesn’t give a version number, then download and install Git.
https://github.com/git-guides/install-git
